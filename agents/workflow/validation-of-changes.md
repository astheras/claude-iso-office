# Валідація змін у коді

Перевірка кожної зміни коду:

1. **`claude plugin test .`** — усі тести зелені. Обов’язково; якщо запустити неможливо — сказати про це явно.
2. **`claude plugin validate .`** — маніфест і модулі плагіна валідні.
3. **Перевірка в панелі.** Агент панелі не бачить. Якщо зміна видима людині, у підсумку попросити перезавантажити плагіни (або перезапустити Claude Desktop) і перелічити, що саме подивитись:
   - які теми зачеплено: «Відсутня» (`none`), «Офіс» (`office`), «Галактика» (`galaxy`);
   - які вкладки: «Огляд», «Легенда», «Налаштування»;
   - кліки по малюнку — з `/office debug` (показує області кліку);
   - поведінку при ширшій/вужчій панелі, якщо мінялись розміри.
4. У підсумку задачі — що перевірено, що **не** перевірено і чому.

## Тести

Нова чиста функція, новий стан чи виправлення бага — з тестом — `agents/typescript/tests.md`.

## Не вважається перевіркою

- «Код виглядає правильно» без запуску тестів.
- SVG-рядок, що «має правильно намалюватись», без перегляду в панелі — для візуальних змін це лише половина перевірки; сказати, що лишилось на перегляд людині.
