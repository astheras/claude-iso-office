# Документація

## README

- `README.md` (англійською) і `README.uk.md` (українською) — опис для користувача. Тримати **синхронними**: будь-яка зміна вноситься в обидва в тому ж коміті, зміст однаковий.
- Змінилась видима поведінка — оновити README: стан чи позначка (список груп, тема «Галактики»), команда `/office …` (таблиця «Використання»), налаштування, нове джерело даних чи обмеження (розділ «Обмеження»: звідки береться і що, якщо файл не прочитано).
- Змінився стан чи позначка — оновити й тексти легенди (`hooks/legend.ts`), вони йдуть за README — `agents/ui/states-and-themes.md`.
- Стиль — як у наявному тексті: звичайні слова про те, що бачить людина, без внутрішніх назв функцій (шляхи файлів і команди — можна).

## docs/

- Плани реалізації великих змін — українською, як `docs/galaxy-plan.md`: що вже відомо, що чим зображено, етапи.
- Створювати лише за запитом.
- Не вигадувати окремий формат (Docusaurus, Wiki тощо), якщо явно не просили.

Правила для агентів — лише в `agents/` (`agents/meta/writing-rules.md`).
