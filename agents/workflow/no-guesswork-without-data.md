# Немає даних — не робити «аби що»

Плагін живе на внутрішніх файлах і викликах застосунку, які ніде не задокументовані. Якщо для реалізації **бракує фактів** про їхній формат — **не здогадуватись і не писати код на припущеннях**. Спочатку з’ясувати.

## Тригери зупинки

- Невідоме поле чи форма запису: рядок транскрипту `.jsonl`, запис застосунку `Claude-Data\…\<чат>.json`, реєстр `sessions\<pid>.json`, `agent-*.meta.json` субагента
- Невідомі поля відповіді `list_sessions` / `get_session`
- Невідомий виклик `$`, подія `on(...)` чи компонент рушія
- Два або більше правдоподібних тлумачення стану сесії (працює / чекає / зупинилась)
- Поле «схоже є» лише за аналогією з іншим записом

## Що робити

1. Зупинити логіку, яка залежить від невідомих даних.
2. Явно сказати, **чого бракує** і що було б лише припущенням.
3. Знайти джерело правди:
   - формат файлів Claude — прочитати реальний файл на цій машині (лише читання, `agents/plugin/app-data-sources.md`);
   - API рушія — типи в `.claude-plugin/types/` і skill `plugin-authoring` (`agents/plugin/engine-api.md`);
   - інакше — запитати користувача.
4. Дозволено лише безпечний мінімум: даних немає — нічого не показувати (рядок акордеону пропускається, група порожня), а не вигадувати значення.

## Заборонено

- Розбирати вигадані поля «щоб працювало»
- Подавати здогадку як формат у коментарі, README чи підсумку задачі
- Мовчазні fallback-и, через які сесія виглядає в «нормальному» стані, хоча дані не прочитано
- Копіювати в репо реальний вміст, прочитаний для з’ясування формату (hard-stop, `agents/README.md`)

## Коли можна продовжувати без уточнення

- Поле вже розбирається в коді (`parse*` з тестом)
- Формат перевірено в реальному файлі в цій сесії
- Користувач **явно** дозволив припущення і прийняв ризик

Доповнює `agents/workflow/clarification-questions-only.md` і `agents/workflow/no-changes-without-explicit-request.md`.
