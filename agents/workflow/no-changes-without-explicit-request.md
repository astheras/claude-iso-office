# Зміни тільки за явним запитом

- **Не редагувати файли**, не створювати/видаляти артефакти в репозиторії, не запускати команди, що змінюють стан проєкту (git commit, push, зміна версії в `plugin.json` тощо), **доки користувач явно не попросить** зробити зміни або конкретну правку.

- **Дозволено без окремого запиту на зміни**: відповіді питаннями, читання та пояснення коду, пошук по кодовій базі, читання файлів Claude для з’ясування формату (`agents/plugin/app-data-sources.md`), запуск тестів (`claude plugin test .`, `claude plugin validate .`), обговорення підходів, пропозиції у тексті відповіді (без застосування в репозиторії).

- Якщо намір неоднозначний (**пояснити** чи **змінити**), **уточнити** перед будь-якими змінами.
