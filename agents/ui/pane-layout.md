# Панель, малюнок і кліки

## Як побудовано

- Панель — дерево компонентів, яке повертає `ui.render` у `hooks/register.tsx`. Малюнок — SVG-рядок з `floorSvg` / `galaxySvg`, масштабований від ширини панелі (`bodyColumns`).
- Кліки по малюнку йдуть не з SVG, а з прозорих кнопок поверх нього, розміщених у символьних клітинках панелі. Розміри клітинки виміряно зі скриншотів десктопа:
  - `CELL_PX` = 7.54 px завширшки;
  - `ROW_RATIO` = 2.65 (у стільки разів клітинка вища, ніж ширша);
  - `EXTRA_COLS` = 0.6 (на скільки малюнок ширший за `bodyColumns`).
- Підпис прозорої кнопки — `BLANK` (braille blank): звичайний пробіл обрізається.
- Підказку кнопка показати не може, тому іконки списку — малюнки з `<title>` і прозорою кнопкою поверх (`hooks/icons.ts`).

## Правила

- Змінюєш розмір чи позицію чогось клікабельного в малюнку — області кліку (`Spot`, `Label`) мають зсунутись разом. У підсумку попросити перевірити з `/office debug`.
- Константи клітинок не міняти «на око»: вони виміряні; нове значення — лише з нового виміру.
- Сцену, що не змінилась, не віддавати новим об’єктом: панель перемальовується на кожному кроці прокрутки і миготить. Для цього `steady()` (`hooks/galaxy.ts`); нова сцена теж іде через `steady`.
- Усі тексти з даних (назви чатів, проєктів, питання) у SVG — лише через `esc()` (`hooks/iso.ts`).
- Кольори — такі, що читаються і на світлій, і на темній темі; заливка смуги поточної сесії — прозорість, а не другий колір (`hooks/current.ts`).
- Ефекти (градієнти, розмиття, `feTurbulence`, маски, `<animate>`) панель підтримує; перевірено в `docs/galaxy-plan.md`.
