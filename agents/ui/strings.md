# Тексти інтерфейсу

## Мова

- Усе, що бачить людина в панелі — вкладки, кнопки, списки, підказки, легенда, примітки (`view.note`), сповіщення — **українською**.
- Англійською: ідентифікатори, коментарі, назви тестів, коміти; опис команди для рушія (`$.command.register`) і `TITLE` панелі — як є.

## Де лежать

Окремого файлу перекладів немає і не створювати. Рядки — поруч з кодом, що їх показує:

| Що | Де |
|----|----|
| вкладки, кнопки, примітки, сповіщення | `hooks/register.tsx` |
| назви груп, `WORD` | `hooks/data.ts` |
| легенда | `hooks/legend.ts` |
| рядки акордеону, тексти станів | `hooks/detail.ts`, `hooks/agents.ts` |
| теми | `THEMES` у `hooks/settings.ts` |
| підписи й підказки малюнка | `hooks/galaxy.ts`, `hooks/floor.ts` |

Тексти, що перевіряють тести (`register.test.tsx` шукає їх регексом), змінювати разом із тестами.

## Як писати

- Коротко і звичайними словами, як у README: що бачить людина, без внутрішніх назв.
- Помилка — що не вдалося і чому, коротко: `Не вдалося відкрити: посилання не розпізнано.`; текст винятку обрізати (`String(err).slice(0, 100)`).
- Час — через `ago` / `agoText` (`hooks/data.ts`), не форматувати заново.
